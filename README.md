# Teste Unitário com Python (PyUnit/unittest)

Projeto desenvolvido na aula prática de Engenharia de Software.

## Estrutura do projeto
- `calculadora.py`: funções da calculadora (somar, subtrair, multiplicar, dividir, potencia, calcular_media).
- `test_calculadora.py`: testes unitários usando o módulo unittest.

## Como executar os testes
```bash
python -m unittest discover
```

## Resultado obtido
```
Ran 8 tests in 0.001s

OK
```
